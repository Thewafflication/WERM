## Release Scope

The intended release is a .NET Framework 4.8 WPF application for Windows x86
and x64. It maintains product, customer, and customer-product price data in
SQLite through ODBC; password-gates data changes; preserves append-only product
and price audit lineage; populates tagged Word content controls; and prints
directly through Word to a selected label printer.

The artifact set is two architecture-specific WPM packages plus controlled
Debug evidence. Version 0.1.0 excludes barcode storage/generation/printing,
PDF generation/printing, scheduled pricing, bulk import, services, and
multi-user database-server operation.
